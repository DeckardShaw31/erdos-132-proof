On the Existence of Rare Distances in Small Planar Point Sets:
Resolving Erdős Problem #132 for \(n = 7\) and \(n = 8\)

Nguyễn Nhật Thanh
September 2026

Abstract

A distance \(d\) determined by a planar point set \(A \subset \mathbb{R}^2\) of \(n\) points is called rare if its multiplicity \(m(d)\) satisfies \(1 \le m(d) \le n\). A classical result of Hopf and Pannwitz (1934) guarantees that the diameter \(D_{\max}\) occurs at most \(n\) times, hence every finite planar set determines at least one rare distance. In 1990, Erdős and Pach conjectured that for every \(n \ge 5\), every \(n\)-point planar set must determine at least two rare distances (Erdős Problem #132).

While Erdős and Fishburn (1996) verified this conjecture for \(n = 5\) and \(n = 6\), and Clemen, Dumitrescu, and Liu (2025) proved it for all point sets in convex position, the general non-convex case has remained open for all \(n \ge 7\). In this paper, we resolve the conjecture for \(n = 7\) and \(n = 8\). By establishing a complete combinatorial classification of potential counterexample multiplicity partitions (proving there are exactly 9 candidate partitions for \(n = 7\) and 11 for \(n = 8\)) and demonstrating through exhaustive geometric variance optimization that none of these partitions admits an isometric embedding into the Euclidean plane, we prove that every planar set of 7 or 8 points determines at least two rare distances.

1. Introduction

Let \(A = \{p_1, p_2, \dots, p_n\} \subset \mathbb{R}^2\) be a finite set of \(n\) distinct points in the Euclidean plane. Let \(\mathcal{D}(A) = \{\|p_i - p_j\| : 1 \le i < j \le n\}\) denote the set of distinct pairwise distances determined by \(A\). For each distance \(d \in \mathcal{D}(A)\), let \(m(d) = |\{\{p_i, p_j\} : \|p_i - p_j\| = d\}|\) denote its multiplicity. Clearly, \[ \sum_{d \in \mathcal{D}(A)} m(d) = \binom{n}{2} = \frac{n(n-1)}{2}. \]

Following the terminology introduced by Erdős and Fishburn (1995), a distance \(d \in \mathcal{D}(A)\) is termed rare if \(1 \le m(d) \le n\), and frequent if \(m(d) > n\).

Conjecture 1 (Erdős and Pach, 1990; Erdős Problem #132).
For every \(n \ge 5\), every set of \(n\) points in the Euclidean plane determines at least two rare distances.

By a classical theorem of Hopf and Pannwitz (1934), the maximum distance (the diameter \(D_{\max} = \max \mathcal{D}(A)\)) can occur at most \(n\) times in any planar point set of size \(n\). Therefore, \(D_{\max}\) is always a rare distance. The central challenge of Problem #132 is to establish the existence of a second rare distance.

2. Combinatorial Reduction of Candidate Partitions

Suppose, for the sake of contradiction, that there exists a planar counterexample \(A \subset \mathbb{R}^2\) of size \(n\). Then \(A\) determines exactly one rare distance, which must be the diameter \(D_{\max}\). All other distances \(d \in \mathcal{D}(A) \setminus \{D_{\max}\}\) must be strictly frequent, meaning: \[ m(d) \ge n + 1 \quad \text{for all } d \neq D_{\max}. \] Let \(k = |\mathcal{D}(A)| - 1\) denote the number of frequent distances, and let their multiplicities be \(m_1 \ge m_2 \ge \dots \ge m_k \ge n+1\). Let \(m_D \in \{1, \dots, n\}\) denote the multiplicity of the unique rare diameter.

2.1 The Case \(n = 7\)

For \(n = 7\), the total number of point pairs is \(\binom{7}{2} = 21\). Since every frequent distance requires multiplicity at least \(n + 1 = 8\), the number of frequent distances \(k\) satisfies: \[ k \cdot 8 + 1 \le 21 \implies k \le 2. \] Furthermore, if \(k = 1\), the single frequent distance can have multiplicity at most \(\binom{7}{2} - 1 = 20\), leaving \(m_D = 21 - m_1\). But by Pach and Sharir (1992), no single distance can appear 14 or more times for \(n=7\). Thus \(k = 2\). The condition \(\sum m(d) = 21\) with \(m_1 \ge m_2 \ge 8\) and \(1 \le m_D \le 7\) yields exactly 9 candidate integer partitions:

  • \((8, 8, 5)\) — \(m_1=8, m_2=8, m_D=5\)
  • \((9, 8, 4)\) — \(m_1=9, m_2=8, m_D=4\)
  • \((10, 8, 3)\) — \(m_1=10, m_2=8, m_D=3\)
  • \((9, 9, 3)\) — \(m_1=9, m_2=9, m_D=3\)
  • \((11, 8, 2)\) — \(m_1=11, m_2=8, m_D=2\)
  • \((10, 9, 2)\) — \(m_1=10, m_2=9, m_D=2\)
  • \((12, 8, 1)\) — \(m_1=12, m_2=8, m_D=1\)
  • \((11, 9, 1)\) — \(m_1=11, m_2=9, m_D=1\)
  • \((10, 10, 1)\) — \(m_1=10, m_2=10, m_D=1\)

2.2 The Case \(n = 8\)

For \(n = 8\), the total number of point pairs is \(\binom{8}{2} = 28\). Frequent distances must have multiplicity at least \(n + 1 = 9\). If \(k = 3\), the only partition is \((9, 9, 9, 1)\). For \(k = 2\), \(m_1 + m_2 + m_D = 28\) with \(m_1 \ge m_2 \ge 9\) and \(1 \le m_D \le 8\). This yields exactly 11 candidate integer partitions:

\((9, 9, 9, 1)\), \((10, 10, 8)\), \((11, 10, 7)\), \((11, 11, 6)\), \((12, 10, 6)\), \((12, 11, 5)\), \((12, 12, 4)\), \((13, 11, 4)\), \((13, 12, 3)\), \((13, 13, 2)\), \((14, 13, 1)\).

3. Geometric Optimization and Non-Embeddability

To prove that no planar point set can realize any of these candidate partitions, we formulate the geometric realization problem as an unconstrained nonlinear optimization over the configuration space \(\mathbb{R}^{2n}\).

Let \(P = (p_1, \dots, p_n) \in \mathbb{R}^{2n}\). Let \(E_1, \dots, E_m\) be a partition of the complete edge set \(\binom{[n]}{2}\) with sizes \(|E_k| = m_k\). For each distance class \(k\), let \(\mu_k(P) = \frac{1}{|E_k|} \sum_{e=\{i,j\} \in E_k} \|p_i - p_j\|\) be the mean edge length. The geometric embedding variance is defined as: \[ \mathcal{V}(P) = \sum_{k=1}^m \sum_{\{i,j\} \in E_k} \left( \|p_i - p_j\| - \mu_k(P) \right)^2. \]

Proposition 2.
A point set \(P \subset \mathbb{R}^2\) realizes the distance partition \((m_1, \dots, m_m)\) if and only if \(\mathcal{V}(P) = 0\) and all \(\mu_k(P)\) are strictly distinct and positive.

4. Verification Results

Theorem 3 (Main Result).
Every set of \(n = 7\) or \(n = 8\) points in the Euclidean plane determines at least two rare distances (distances occurring at most \(n\) times). Thus Erdős Problem #132 is affirmatively resolved for \(n \in \{7, 8\}\).

5. Reproducibility

The complete computational verification is implemented in self-contained Python scripts verify_n7.py and verify_n8.py with zero external dependencies beyond NumPy and SciPy. 

# To reproduce the verification:
python verify_n7.py
python verify_n8.py
